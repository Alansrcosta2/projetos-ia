# projetos-ia — 49 projetos de IA (mapa-100 + mapa-101)

Repositório único que reúne, em pastas separadas, os 49 projetos de IA de código aberto dos materiais:

- mapa-100: https://andrelug.com/materiais/mapa-100
- mapa-101: https://andrelug.com/materiais/mapa-101
- claude-100 (EGM do Google): https://andrelug.com/materiais/claude-100

## Conteúdo

| Arquivo | O que é |
|---|---|
| `CATALOGO.md` | Catálogo dos 49 projetos por categoria e por tarefa |
| `LINKS.md` | Links de origem e repositórios do GitHub |
| `MATERIAIS/claude-100-egm.md` | Resumo do material EGM (instalação, 7 comandos) |
| `repos.txt` | Lista `owner/repo` usada pelo script |
| `INSTRUCOES.md` | Passo a passo para publicar pelo servidor |
| `montar_repo.sh` | Script que clona, monta e envia tudo para o GitHub |
| `elephant-goldfish-model/` | Código do EGM (claude-100), incluído além dos 49 projetos |
